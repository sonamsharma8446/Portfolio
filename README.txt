# Premium AI-Assisted Glassmorphic Portfolio

A high-fidelity, modern, responsive personal portfolio website engineered for **Sonam Sharma** (Computer Science Engineering Student & Aspiring Full Stack Developer). This project features a clean glassmorphic aesthetic, interactive ambient backgrounds, and fluid scroll animations built using semantic HTML5, CSS3, and vanilla modern JavaScript.

---

## 🚀 Core Features

* **Glassmorphic UI Design:** High-end translucent structural components using calibrated `backdrop-filter` values, precise borders, and elegant drop shadows.
* **Ambient Background Matrix:** Integrated dynamic node-link visual elements using **Particles.js** to reflect an advanced, AI-centric design language.
* **Dual-Theme Engine:** Toggle dynamically between a dark color canvas (Navy/Purple/Cyan profiles) and a high-contrast light mode canvas.
* **Live Typewriter Effect:** Embedded asynchronous title rotation using **Typed.js** to maximize text real estate in the hero layout.
* **Asynchronous Scroll Transitions:** Section reveals handled via **AOS (Animate On Scroll)** for clean UI entry points without compromising execution speeds.
* **Fully Responsive & Accessible:** Built from the ground up using mobile-first Media Queries, semantic elements, and keyboard-navigable structures.
